# Tiger School LP Admin Prototype

Standalone, self-contained HTML prototype for Tiger School learning partners (LPs).

## Run

Open `huxiao-lp-console-demo.html` directly in any modern browser. It uses only embedded HTML, CSS, JavaScript, and mock data; no server, build tool, package install, or network access is required.

## Demo flows

- Workbench task queue → student record drawer → contact note and next follow-up → task status/time-line update.
- Student list search/filter, course status and mock scheduling, service node completion, campaign/reward follow-up, and supplementary purchase/renewal intent.
- Refresh resets all in-memory changes to initial demo state.

## Boundaries

All information is simulated. The prototype does not send real messages, book classes, grant rewards, create orders, accept payment, sync with external systems, or enforce leave/suspension eligibility rules. UA, upgrade, and renewal service nodes are marked planned/not implemented. Reward criteria are activity-specific and deliberately not generalized into a single formula.
